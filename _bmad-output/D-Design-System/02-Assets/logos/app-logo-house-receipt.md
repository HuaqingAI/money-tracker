# App Logo: House Receipt [logo-001]

**Type:** Brand Logo  
**Status:** Approved direction  
**Source:** `app-logo-house-receipt.svg`  
**Last Updated:** 2026-05-13

## Concept

Logo 以「家 + 消费小票 + AI 闪光」为核心意象，表达了然面向家庭消费场景的零记账财务管家定位。外层扫描框暗示自动捕获，房屋轮廓承接家庭账本，小票承接消费记录，右侧闪光承接 AI 识别和洞察。

## Visual Anatomy

| Layer | Description |
|-------|-------------|
| App icon container | 1024x1024, rounded square, 220px corner radius |
| Background | Aqua to mint gradient with soft radial highlights |
| Scan frame | White corner frame, communicates automatic capture |
| House shape | Soft white translucent house silhouette |
| Receipt card | White receipt with category/amount line placeholders |
| AI sparkle | Warm yellow sparkle, secondary emphasis |
