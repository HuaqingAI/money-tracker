# High-Fidelity Mapping Checklist（页面保真映射模板）

- **Owner**: Developer（每个页面填写一份） + UX Designer（review）
- **使用范围**: 所有涉及页面/组件 UI 的 Story，在 review 前必须填写本模板
- **目的**: 把 NFR8 视觉保真度（核心 90% / 次要 80%）的判定从主观感受变成可复核的逐项勾选
- **创建日期**: 2026-04-29
- **关联文档**: `sprint-change-proposal-2026-04-29.md` §4.5；`prd-bridge.md` NFR8

---

## 使用方式

1. 每个涉及 UI 的 Story，在进入 review 前由 Dev 复制本模板到 Story 文件或独立附件
2. 逐条填写，**不允许跳过**；无法判定的项写"N/A + 原因"
3. 保真度自评低于阈值 → 不得进入 review，回到实施
4. UX Designer 在 review 阶段核对本模板，偏差项必须登记原因并给出后续修复计划

---

---

## 质量闸门

本模板的勾选被 Story review 视为 mandatory artifact。review 阶段若发现：

- 模板未填写 → review 拒绝
- 自评 < 阈值但未登记偏差 → review 拒绝
- 偏差登记但未指定处理路径 → review 拒绝
